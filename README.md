# Student Registration QA - React + TypeScript + Tailwind

โปรเจกต์นี้สร้างใหม่จากแบบฟอร์ม HTML เดิม โดยเปลี่ยนเป็น React + TypeScript + Tailwind CSS

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

หมายเหตุ: BUG #1 และ BUG #2 จากไฟล์ HTML เดิมถูกคงไว้โดยตั้งใจ เพื่อให้หน้าเว็บยังใช้เป็นโจทย์สำหรับการทำ QA/Functional Testing ได้เหมือนเดิม
